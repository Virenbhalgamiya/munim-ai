# Dataset: Sharma General Store (owner: Ramesh)

Generated by `python data/generate_dataset.py` (seed 42, deterministic). Re-run it any time; the numbers stay the same.
Use `--end-date YYYY-MM-DD` to shift the 60-day window.

| File | Contents |
|---|---|
| `merchant_transactions.json` | Everything: `store`, `period`, `catalog`, `regulars`, `udhaar`, `transactions` (with item lists). The app reads this file. |
| `merchant_transactions.csv` | One row per UPI transaction (items flattened into a string). |
| `udhaar_ledger.csv` | The credit ledger. |

**Period:** 2026-08-04 → 2026-10-02 (60 days, ending the day before the 3 Oct hackathon). About 3,600 transactions.
"Today" in the app means **2026-10-02 (Friday)** unless `DEMO_TODAY` is set.

## Udhaar schema
`customer_name, aliases, outstanding, credit_since, last_payment_date, last_payment_amount, phone, telegram_chat_id, note`
Overdue rule used by the tools: **no payment for more than 10 days**.
